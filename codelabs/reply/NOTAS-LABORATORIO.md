# Codelab de temas de Material 3

La carpeta `ThemingCodelab` parte de la rama `main` del [repositorio oficial de codelabs de Compose](https://github.com/android/codelab-android-compose/tree/main/ThemingCodelab). Se conservan sus licencias y recursos originales.

Se ha comenzado el [codelab de temas](https://developer.android.com/codelabs/jetpack-compose-theming?hl=es-419), con colores claros y oscuros, colores dinámicos, formas y estilos de texto en las vistas de lista y detalle. La tarea `:app:assembleDebug` compiló correctamente. Una versión anterior permitió abrir la lista y el detalle; después se conectó el tema y se comprobó visualmente la lista en modo oscuro. Falta volver a comprobar la vista de detalle con el tema aplicado. La base oficial emite advertencias sobre API y opciones de Gradle obsoletas.
